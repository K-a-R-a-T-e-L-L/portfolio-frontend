# ScatteringSkull background

Original: ScatteringSkull, Vladimir Petkovic / Khronos glTF Sample Assets.
https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ScatteringSkull
License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/

scattering-skull.glb is a derivative generated by scripts/prepare-skull.mjs:
node scripts/prepare-skull.mjs /absolute/path/to/original/ScatteringSkull.glb

Original: 8,959,044 bytes, 188,871 triangles, no rig or animations.
Derivative: 3,638,772 bytes, same triangles; two meshes with a jaw pivot.
Unused textures, UVs and tangents are omitted. Positions are unchanged. Normals use normalized signed bytes with four-byte stride (KHR_mesh_quantization), keeping the same topology and shading directions.
The jaw selection matches the user-approved separate prototype. It is an
approximate spatial cut; boundaries near teeth/joints remain imperfect.
No external model requests are made at runtime. The app supplies its own material.

skull-poster.webp is generated from the local renderer for reduced motion,
no-WebGL and no-JavaScript fallback. Do not edit generated assets by hand.
