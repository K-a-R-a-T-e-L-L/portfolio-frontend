# Portfolio fonts

Inter by Rasmus Andersson and Manrope by Mikhail Sharanda, Cyrillic and Latin WOFF2 subsets.
These are the same Google Fonts files already downloaded by this project's previous Next.js build,
now stored as source assets to remove build-time network dependencies.

- https://fonts.google.com/specimen/Inter
- https://fonts.google.com/specimen/Manrope
- Original license texts: Inter-OFL.txt and Manrope-OFL.txt (Google Fonts repository).

No font data was modified. Unicode ranges are declared in src/app/globals.css.
